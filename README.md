# Lab 6 – Strings in C++

## Introduction
This lab focuses on string handling and basic string operations in C++.

## Objectives
- Understand C++ strings.
- Perform basic string operations.
- Reverse and compare strings.
- Count vowels and consonants.
- Practice string manipulation.

## Programs
1. Palindrome Checker
2. Count Vowels and Consonants
3. Reverse a String
4. Count Characters
5. Convert to Uppercase
6. Check First and Last Character
7. Concatenate Two Strings

## Technologies
- C++
- VS Code
- GCC Compiler

## Testing
All seven programs were compiled and tested successfully.

## Learning Outcome
Learned string declaration, input, comparison, concatenation, and character manipulation in C++.
